# Delivery Code Studio — Android project

A premium blue-and-yellow Android WebView app for generating QR codes and Code 128 barcodes from manually entered text, scanning existing labels, local history, PNG download/share, and printing.

## Important
- This is an independent utility and is not affiliated with or endorsed by Flipkart.
- Generated codes are not official Flipkart tracking, pickup, OTP, or delivery codes.
- The QR/barcode and scanner JavaScript libraries load from CDNs, so an internet connection is needed for code generation/scanning in this starter project.
- Camera scanning requires granting camera permission at runtime / when prompted by WebView.

## Build an APK
1. Open this folder in Android Studio (current stable).
2. Allow Gradle sync to complete and install Android SDK Platform 35 if prompted.
3. Choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Android Studio will show the generated APK location, normally `app/build/outputs/apk/debug/app-debug.apk`.

This environment did not have Android SDK/Gradle available, so an APK binary is not included in this ZIP. The complete Android Studio source project is included.
